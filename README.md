# Shehzad Ali — Portfolio (React + Vite)

    npm install
    npm run dev      # local

Edit content in `src/data.js`. Project images: put `1.jpg`, `2.jpg`, `3.jpg` in `public/projects/<slug>/`
(slugs: gh-sons-erp, barriocheck, centrixhub, kaduuka, the-mirror, adams-pills, eros-him). Missing images show a placeholder.
Add `live:` / `github:` URLs in `data.js` to show link buttons.
